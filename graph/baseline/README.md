# Baseline graph — sanitized static source

[Owner-private live graph](https://soup-baseline-graph.contributor.chatgpt.site). Original deployed source commit: `ebc9d92876ac431eaa7886d6679d7c050720fa32`. This directory is a repository mirror, **not a new deployment**.

Open `index.html` with its adjacent static files, or serve this directory with an ordinary local static server. No build step, dependency installation, network API, credentials or runtime state is required. `graph.json` is also the baseline-only sample for `schema.json`; `data.js` embeds the same graph so the viewer does not require a fetch.

One baseline node is one configuration bucket/subgraph and one conceptual point at X=0, Y=0. Z, admission, time, peak memory, loss and earned points remain unknown. There are no tested candidates, candidate-creation controls, edges, comparisons or runs. CPU fixture evidence never becomes a T4 performance point. Future nodes require linked completed testing; buckets contain the complete idea IDs and typed settings, not inherited gains.

Only absolute cloud evidence/catalog paths have been replaced with repository links. The original 118-row initial-catalog metadata is retained for historical provenance; [the closed cycle 2 catalog](../../research/cycles/20261030-cycle2/) contains 121 rows. This publication does not mutate the table or live site. Hosting IDs, source/archive machine paths, `.git`, `.openai`, credentials and superseded proposal-node prototypes are excluded.

`publication.json` records the prior deployment's reported verification and limitations. Run the [snapshot verifier](../../research/cycles/20261030-cycle2/verify_snapshot.py) for the packaged bytes and baseline-only invariants. The live view was previously cloud-browser inspected; mobile layout was not browser-tested. No performance or official-score result is implied.
