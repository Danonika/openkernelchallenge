# Soup Kernel Challenge

Оптимизация обучения LoRA на одной NVIDIA T4. Решение сохраняет модель и формат NF4, сокращая временные буферы и число запусков CUDA-операций. Точка входа: `solution.apply()`.

## Результат

Историческая сессия Kaggle v1: **47,73 с вместо 86,39 с (1,81× быстрее)**, **2 263 MiB вместо 14 345 MiB (на 84,2% меньше)**. Схема измерения: база → решение → решение → база.

| Метрика | Базовый Soup | Решение |
|---|---:|---:|
| Полное время команды, медиана двух запусков | 86,39 с | **47,73 с** |
| Время цикла обучения, медиана двух запусков | 62,95 с | **33,63 с** |
| Пиковая память GPU, максимум двух запусков | 14 345 MiB | **2 263 MiB** |
| Eval loss | 2,04966 | 2,04984 (+0,009%) |

В сохранённом запуске прошли **10/10 проверок** и **79/79 регрессионных тестов**. [Исходные метрики](docs/evidence-final-v1/result.json) · [Отчёт проверок](docs/evidence-final-v1/checks.json). Результаты относятся к одной исторической конфигурации T4/fp16. Публичная копия очищена от личных данных; нового запуска после очистки не было. Числа в таблице и файлы метрик и проверок не изменены.

## Что изменено

- **Выходная проекция:** обработка словаря блоками без хранения полного тензора логитов. Все 151 936 столбцов участвуют в вычислениях.
- **MLP:** в обратном проходе пересчитываются gate/up-проекции, чтобы не хранить широкие активации.
- **NF4 и QKV:** общая деквантизация и группировка операций при сохранении формата NF4.
- **RMSNorm, RoPE и padding:** сокращение временных тензоров, приведений типов и вычислений на padding.

## Как запустить

Рекомендуемый старт: [ноутбук для Kaggle](notebooks/Soup-Duo-Final-Submission-v1.ipynb) с GPU **T4**. Он устанавливает зависимости, распаковывает встроенный исходный код и проверяет его контрольные суммы. Токен GitHub и дополнительные ветки не нужны. Для первоначальной установки пакетов и загрузки модели и датасета нужен доступ в интернет. Текущий ноутбук не запускался повторно после очистки.

Эквивалентный порядок команд в подготовленной CUDA-среде:

```bash
python -m pip install -r requirements.txt
python task/prepare_data.py
python harness/run_task.py --repeats 2 --timeout 900
python harness/check_rules.py
python harness/score.py runs/result.json
```

Нагрузка: Qwen2.5-1.5B-Instruct, Soup 0.77.0, NF4 double quantization, LoRA `r=16` / `alpha=32` на `q_proj` и `v_proj`, batch 4, длина до 512 токенов, 256 инструкций и 64 шага. Полное время включает загрузку, компиляцию и сохранение адаптера. Результаты на другой GPU или в другой сессии могут отличаться.
