# Public branch integration

The submitted kernel, dependencies, harness, and top-level submission notes
on this branch are unchanged from the sanitized pre-merge main. The added
research, evidence, notebooks, service, and queue files are archival. This
merge does not represent a new benchmark run or confirm any performance
reported in the added material.

All published variant histories are reachable from this merge and their
branch names are retained. Where different variants used the same path,
or would alter the submitted runtime or configuration, the alternate
implementations remain on their original branches rather than replacing main.

The original CI workflow is retained only as disabled archival reference.
