## Size budget

Qwen2.5-1.5B-Instruct is 28 layers, 1536 hidden, 8960 MLP, 151936 vocab, a tied embedding and ~1.31B nonembedding parameters. At resident 4-bit nonembedding + FP16 tied embedding + FP32 LoRA weights/Adam/grads, a deliberately optimistic arithmetic subtotal is **~1123 MiB**, excluding extra metadata and intermediate tensors. The queue's simple GPU smoke reported ~143 MiB. Together these suggest only **~93 MiB headroom** under the requested 1359 MiB, even before live activations, score tiles, workspaces, and extra runtime buffers. This is a conditional sizing argument, not a proof of impossibility. A full FP16 output-score tensor at maximum batch shape is ~593.5 MiB. A 256-token tile alone is ~74.19 MiB.

To reach both targets would likely require aggressive fused NF4 dequant+Tensor-Core matmuls, a true memory-bounded fused projection/loss, and selective CPU weight offload or own-code activation rematerialization, all without altering any task settings. On SM75 Triton 3.6 plain `tl.dot` is not equivalent to a fast Tensor-Core kernel; own `mma.sync` work needs device-level correctness and throughput evidence. Do not import or copy prohibited kernel packages.
